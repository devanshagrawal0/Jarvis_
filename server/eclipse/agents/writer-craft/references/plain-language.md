# Plain language target

- Flesch Reading Ease 55–75 per section (lint checks this). That is roughly: sentences
  averaging 15–20 words, words averaging under 1.6 syllables.
- Prefer the short common word when it says the same thing.
- Define a technical term once, in-line, the first time it appears — or do not use it.
- Numbers: digits, with units, with the year when the value is time-bound.
- Lists of three or more parallel items become bullets (keyfacts), not a run-on sentence.
- A section a reader can scan in ten seconds is a section that will be read.
