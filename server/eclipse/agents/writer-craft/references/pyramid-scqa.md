# Pyramid + SCQA — how to order a deliverable

## Minto pyramid (every artifact type)
- Top: the answer, one sentence.
- Middle: the 2–5 supporting points, each a claim-backed sentence.
- Bottom: the data (numbers, table rows, quotes) under the point it supports.
- A reader who stops after any line has still read something true and complete.

## SCQA opening (memo / report lead only)
- **Situation** — one sentence of shared context the reader already accepts.
- **Complication** — what changed or what is at stake (from the claims, not from opinion).
- **Question** — the mission's actual ask, restated in the reader's words.
- **Answer** — the pyramid top.
The lead is 3–5 sentences. It is written LAST, after the body exists.

## Grouping
- Group by the reader's question (contract requirement), not by source.
- Order groups by importance to the ask, not by discovery order.
- Within a group: conclusion → evidence → detail.

## Comparison type
- Verdict sentence first, then the table (dimensions as rows, subjects as columns, a source
  column last), then at most one paragraph per dimension where the table cell needs words.

## Timeline type
- Outcome first ("By March the plant was closed."), then the sequence, each step dated and
  claim-backed. No step without a date from a claim.
