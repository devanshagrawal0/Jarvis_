# ADR-017: Retrieval Is a Budgeted Policy Action

- Status: Accepted for Wave 18
- Date: 2026-07-25

Retrieval is not an unconditional preamble to every response. An inspectable deterministic gate chooses none, working-only, exact, hybrid, live-domain, or deep work from task risk, uncertainty, expected value, latency, cost, freshness, and working-state sufficiency.

Exact truth retains priority over fuzzy rank and learned utility. Mid-task retrieval is allowed only at typed failure/uncertainty checkpoints and within a per-task budget. Learned routing or reranking may replace a rule only after counterfactual evaluation and can never override authorization, directives, truth, time, provenance, or safety.
