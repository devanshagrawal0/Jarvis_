# ADR-018: Context Is a Reproducible Derived Package

- Status: Accepted for Wave 19
- Date: 2026-07-25

Model context is a versioned, budgeted projection of authorized working state and retrieval results—not memory authority and not concatenated chat history. Every pack binds its model/effort profile, source record versions, ordering, hashes, scope, consistency watermark, reserves, and abstention condition into a deterministic encrypted manifest.

Protected directives cannot be truncated or silently removed for provider eligibility. Untrusted retrieved material has no instruction authority. Influence receipts distinguish delivered from demonstrably used context; uncertain usage remains unknown.
