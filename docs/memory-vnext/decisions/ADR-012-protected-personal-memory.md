# ADR-012: Protected Personal Memory Is Not Inferred Text

- Status: Accepted for Wave 13
- Date: 2026-07-24

Owner identity and hard directives require an active owner actor on a trusted owner authority surface. Identity values must exactly match a current owner-asserted assertion. Model, agent, imported, and untrusted content cannot create these protected records.

Inferred preferences remain sourceable candidates until owner promotion. Conditions remain explicit and scope-aware. Goals and commitments use typed transition graphs and versioned encrypted events. A model may propose work, but it cannot silently activate or rewrite owner goal truth.
